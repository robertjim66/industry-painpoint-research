# 输入样例 · Sample Inputs

> 下面是 5 组可以直接复制使用的启动提示词。每组标注了适用场景、会触发的档位，以及你应该期待什么。
>
> 这些是**真实可用的输入**（不像输出样例那样是示意的）。

---

## 1. 最简启动 —— 让 skill 反问你

```
研究一下第三方医学检验行业
```

**适用**：你还不确定自己要什么，想先看看这个 skill 会问什么。
**会发生**：它先反问三件事（深度档位 / 关注领域 / 已有认知），你回答后才开工。

---

## 2. 带档位 —— 快速判断值不值得深挖

```
快速扫描一下「冷链物流」，我想知道值不值得投入两周做深入研究
```

**触发档位**：🚀 快速扫描（2 个子代理，3–5 分钟）
**产出**：执行摘要 + 痛点矩阵精简版，约 800–1500 字
**适合**：一次性判断多个候选行业时的初筛

---

## 3. 带目的 —— 做 AI 落地方案前的切入口定位

```
我在给一家区域连锁体检机构做 AI 赋能方案。
请标准研究「第三方医学检验」行业，重点关注中下游环节，
我已经知道的情况是：他们的核心痛点是报告出具慢和医生解读能力参差。
不用从零讲行业基础。
```

**触发档位**：🔍 标准研究（4 个子代理，8–15 分钟）

**这段提示词里三个值得学的写法**：

| 写法 | 作用 |
|---|---|
| 说明**服务对象**（区域连锁体检机构） | 让「付费意愿」这一维打分有锚点，而不是泛泛而谈 |
| 限定**关注环节**（中下游） | 省掉上游试剂设备的无用篇幅 |
| 交代**已有认知** | 避免它花时间讲你已经知道的东西 |

---

## 4. 带验收标准 —— 要能拿去汇报

```
深度尽调「工业无损检测」行业。
这份报告要拿去做投资决策，所以每个数字都要有来源，
找不到就明确标注「数据不足」，不要估算填充。
```

**触发档位**：🏗️ 深度尽调（4 个子代理 + 额外验证，20–40 分钟）
**产出**：8 章 + 附录 + 数据表

**最后那句不要省**。虽然 14 项质检里已经写了「数据不足是合法答案」，但你显式强调一次，能显著减少它为了「显得完整」而补推测的倾向。

---

## 5. 自定义痛点类型 —— 覆盖八类之外

```
研究「生猪养殖」行业的 AI 落地机会，标准研究。
除了默认的八类痛点，额外帮我看两类：
1. 疫病防控与生物安全
2. 环保合规压力（粪污处理）
```

**适用**：你知道这个行业有特殊痛点，但不确定它会不会被第 8 类动态识别捕获。
**会发生**：这两类会作为额外检查项进入痛点猎手的排查清单，并参与四维打分和排序。

---

## 通用技巧

**想让它更准，就多给一句「你是谁、要拿去干什么」。**

同一份行业报告，给投资人看和给客户做方案看，重点完全不同——但 skill 不知道你是谁。你多说一句，付费意愿那一维的打分就准一个档次。

**想让它更快，就明说档位。**

不确定时它会默认按标准研究跑。如果你只是想初筛，直接说「快速扫描」能省 10 分钟。

**想让它更诚实，就显式允许它说不知道。**

见样例 4。这一句的效果比你想的大。

---

## 不该怎么写

| ❌ 别这样 | 为什么 |
|---|---|
| `帮我做个行业调研` | 没说行业，它会反问；即使补了，也不知道你要多深 |
| `写一份完整的行业报告，越详细越好` | 没有档位概念，会默认全量跑，慢且重点散 |
| `这个行业规模有多大？给我准确数字` | 「准确」不是你能要求的，是来源决定的。它会给你带来源的数字，没有就写数据不足 |
| `不要说不知道，尽量估算` | 直接废掉整套反编造机制，输出会变成看起来很专业的编造 |
