# 行业痛点研究报告模板

> **使用说明**: 本报告模板定义了8章完整报告的标准结构。每章包含标题、字数要求、必须包含的内容元素和图表类型。执行报告合成时，严格按此骨架填充。

## ⚠️ 档位适配（先读这段）

本模板的**字数要求是「标准研究 / 深度尽调」两档的标准**，不适用于快速扫描档。三档对应关系：

| 档位 | 适用章节 | 字数口径 | 图表 |
|------|---------|---------|------|
| 🚀 快速扫描 | **仅第 1 章 + 第 4 章精简版** | 合计 800–1500 字 | 只保留综合优先级气泡图 |
| 🔍 标准研究 | 第 1–7 章（第 8 章简化） | 按下表字数执行 | 每章保留 1 张主图 |
| 🏗️ 深度尽调 | 第 1–8 章全量 | 按下表字数执行，第 8 章追加数据表 | 全量 |

**规则**：档位与字数冲突时，**以档位为准**。快速扫描档不得套用全量字数要求——那是 3–5 分钟内跑不完的。
快速扫描档的「最小可行报告」见 SKILL.md 降级策略一节。

## 1. 执行摘要

**目标**: 让读者在3分钟内了解全貌
**字数**: 800-1200字

### 必须包含
- [ ] 一句话定义行业
- [ ] 核心发现（3-5条，每条1句话）
- [ ] 高优先级AI机会（3-5个，含痛点名称 + 预期收益 + 落地难度）
- [ ] 关键数据锚点（市场规模、增速、痛点普遍性数值）
- [ ] 行动路线图（30天/90天/1年建议）

### 必须包含

## 写作规范

### 风格要求
- **口语化**: 用"你"对话，避免"我们认为"
- **具体化**: 数字说话，避免"很多"、"大量"
- **可视化**: 能用图表不用表格，能用表格不用文字
- **行动导向**: 每个发现必须指向一个行动

### 禁区
- 无来源的断言
- 过时数据（>2年需标注）
- 编造的数字
- 过度营销语言
- 与主题无关的内容

### 质量自检清单
- [ ] 每个断言有来源
- [ ] 交叉验证完成
- [ ] 时效性检查（优先近12个月）
- [ ] 信息缺口明确标注
- [ ] 事实与推断区分
- [ ] 包含反证
- [ ] 决策导向
- [ ] 来源可追溯
- [ ] 偏见控制
- [ ] 逻辑链完整
- [ ] 结论有依据
- [ ] 行动可执行
- [ ] 表达清晰
