# 子代理任务分配模板

## 子代理1：行业扫描员

```
任务：对[行业名称]进行全面行业扫描，建立行业全景认知。

搜索关键词组（[当前年份] 用运行时实际年份替换，禁止照抄示例）：
- "[行业] 市场规模 [当前年份] 增速"
- "[行业] 发展趋势 未来 3 年"
- "[行业] 产业链 价值链 供应链"
- "[行业] 主要企业 竞争格局"
- "[行业] 政策 法规 监管"
- "[行业] 关键指标 数据"
- "[行业] 前沿技术 创新"

数据来源优先级：
- P0: 艾瑞/IDC/Gartner/麦肯锡/德勤行业白皮书
- P0: 上市公司年报/招股书
- P1: 券商研报
- P1: 行业垂直媒体

输出要求（结构化）：
1. 市场规模与增速（带数据来源和日期）
2. 价值链结构（上下游关系图，文字描述）
3. 3-5个核心指标（Base Rate：指标名 + 数值 + "这意味着"一句话点评）
4. 3个前沿问题（未决的、能改写格局的、一句话锋利表达）
5. 瓶颈位置（稀缺产能/单点控制/牌照专利/认知极限）
6. 价值捕获点（议价权/高毛利/赢家通吃）
```

## 子代理2：竞争情报员

```
任务：绘制[行业名称]的竞争图谱，解构价值链上每个环节的参与者。

搜索关键词组：
- "[行业] 龙头企业 排名 市场份额"
- "[行业] 主要公司 业务 产品"
- "[行业] 新进入者 挑战者 颠覆者"
- "[行业] 上市公司 财报 业务构成"
- "[行业] 融资 投资 估值"

输出要求（结构化）：
1. 参与者分层清单：
   - 直接玩家（核心业务环节头部企业）
   - 相邻玩家（边缘施压的跨界者）
   - 向往玩家（行业标杆/颠覆者）
   - 替代品威胁（AI工具/内部团队/外包）
2. 每个参与者的8轴画像：
   - 定位姿态、专业化、规模/模式、合作形式、独特性姿态、证据/可信度模型、品牌力、市场/覆盖
3. 价值链 × 参与者矩阵
```

## 子代理3：痛点猎手

```
任务：深挖[行业名称]的八类痛点（7 类固定 + 1 类动态），从多个信息源交叉验证。

搜索关键词组（从业者声音）：
- "[行业] 从业者 吐槽 问题 难"
- "[行业] 日常 工作 痛点"
- "[行业] 最讨厌 工作 内容"
- "[行业] 知乎 问题"

搜索关键词组（岗位需求）：
- "[行业] 招聘 岗位 需求"
- "[行业] 招人 难 留人"
- "[行业] 薪资 涨幅 薪酬"

搜索关键词组（效率与决策）：
- "[行业] 效率 低下 问题"
- "[行业] 数字化 程度 低"
- "[行业] 审批 流程 繁琐"
- "[行业] 数据孤岛"
- "[行业] 决策 困难 数据"

搜索关键词组（知识与经验）：
- "[行业] 经验 传承 知识管理"
- "[行业] 新人 培训 周期"
- "[行业] SOP 标准流程"
- "[行业] 师傅带徒弟"

搜索关键词组（客户反馈）：
- "[行业] 客户 投诉 问题"
- "[行业] 差评 问题"
- "[行业] 获客 成本 营销"
- "[行业] 客户 留存 复购"

输出要求（结构化）：
1. 八类痛点清单，每类包含：
   - 痛点描述（1-2句）
   - 识别信号（3-5个具体表现）
   - 从业者原声引用（带来源）
   - 普遍性/严重度/付费意愿/AI适配度评分（1-5）
2. 痛点优先级排序（按综合得分）
```

## 子代理4：AI侦察兵

```
任务：扫描[行业名称]的AI解决方案现状和技术可行性。

搜索关键词组（AI应用现状）：
- "[行业] AI 人工智能 应用 案例"
- "[行业] 数字化 智能化 实践"
- "[行业] AI工具 产品 解决方案"
- "AI [行业] startup 创业"
- "[行业] 智能客服 智能推荐 智能分析"

搜索关键词组（技术可行性）：
- "[行业] 机器学习 深度学习 应用"
- "[行业] NLP 自然语言处理"
- "[行业] 计算机视觉 图像识别"
- "[行业] RPA 自动化 机器人"
- "[行业] 大模型 LLM 应用"

搜索关键词组（政策与趋势）：
- "[行业] AI 政策 支持 规划"
- "[行业] 数字化转型 政策"
- "AI [行业] 市场规模 投资"

输出要求（结构化）：
1. 现有AI解决方案清单：
   - 方案名称 + 提供方
   - 解决的痛点
   - 覆盖范围与效果
   - 用户反馈
2. 未被满足的AI需求（白地）
3. 技术可行性评估：
   - 数据可得性
   - 技术成熟度
   - 实施难度
4. 政策导向（支持/限制）
```
