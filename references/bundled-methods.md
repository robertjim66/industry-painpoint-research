# 内置方法库（自包含）

> **为什么有这个文件**：本 skill 早期版本把部分方法外包给其他 skill（competitive-platform-analysis、competitive-report-structure、deep-research 等）。
> 但分享给别人时，对方环境里大概率没有这些 skill，一触发就报错。
> 所以把**真正用得上的那部分方法原样内化到这里**，让本 skill 零外部依赖即可完整跑通。
>
> **用法**：外部技能一律视为「可选增强」，不是前置条件。没装就按本文件执行，效果不打折。

## 一、竞争分层：四层分类法

用于「参与者图谱」章节。分类标准要写进报告，不能凭感觉分层。

| 层级 | 定义 | 判定标准 |
|------|------|---------|
| **直接玩家 Direct** | 核心业务环节的头部企业 | 同一规模带 + 业务重叠 + 争夺同一批客户 |
| **相邻玩家 Adjacent** | 边缘施压的跨界者 | 部分重叠（只重叠一项能力，或客户规模不同） |
| **向往玩家 Aspirational** | 行业标杆 / 颠覆者 | 今天不构成竞争，但其品牌或商业成熟度是标尺 |
| **替代品威胁 Substitutes** | AI 工具 / 内部团队 / 外包 | 记为威胁向量，通常不做完整画像 |

**分层纪律（常见错误）**：
- ❌ 把所有相似公司都列进来 —— 目标是 **10–18 个候选 → 8–12 个画像**，不是普查。不做剪枝会让后续分析失控。
- ❌ 四层混为一谈 —— 四层的战略用途不同，混在一起只能得到一张扁平名单，驱动不了决策。
- ❌ 每个企业只查一个来源 —— 企业自述的官网文案是营销不是事实，**至少两个来源交叉验证**。

## 二、8 轴画像（完整定义与打分口径）

用于核心参与者的结构化对比。每个轴 1–5 分，两端定义如下，**按两端打分，不要取中间值糊弄**。

| # | 维度 | 一端（1 分） | 另一端（5 分） |
|---|------|-------------|---------------|
| 1 | 定位姿态 | 能力导向（拼产能、交付、结果） | 品牌/观点导向（拼身份、话语、立场） |
| 2 | 专业化 | 通才（业务面宽） | 专家（单一环节/单一垂直） |
| 3 | 规模 / 模式 | 小微 / 单干 | 平台型 / 企业级 |
| 4 | 合作形式 | 封闭自建 | 开放生态合作 |
| 5 | 独特性姿态 | 常规保守 | 反主流 / 有明确主张 |
| 6 | 证据 / 可信度模型 | 资源驱动（关系、牌照） | 结果驱动（数据、案例、可验证指标） |
| 7 | 品牌力 | 可替代、无辨识度 | 行业内有占位、有认知壁垒 |
| 8 | 市场 / 覆盖 | 区域 / 局部 | 全国 / 全球 |

**预筛规则**（决定哪些企业值得做完整画像）：

| 组合 | 结论 |
|------|------|
| 独特性高 **且** 可信度高 | **必须画像** —— 证明目标位置可达 |
| 独特性高、可信度低 | **警示案例** —— 有特点但不成气候，是失败模式样本 |
| 可信度高、独特性低 | **"能干但没记忆点"** —— 代表行业多数派 |
| 两者都低 | 直接放弃，除非需要撑开样本面 |

> **注意**：本 skill 面向传统行业（制造业、医疗、教育、物流等），轴 1/5/6 的含义会与创意服务行业不同。
> 打分时在报告里写明该行业下每根轴的具体含义，不要照搬字面。

## 三、报告组装原则

用于「报告合成」阶段。这几条决定了报告是决策材料还是文献综述。

1. **先结论，后方法论。** 执行摘要开门见山给最重要的发现和方法之外的东西；方法论一律放附录。不要在摘要里解释"我们是怎么调研的"。
2. **每张图必须承载论点。** 2×2 定位图 / 热力图优先于大段文字。表格要能扫读，原始证据和链接推到附录。
3. **矩阵不加"综合总分"列。** 混合总分会造出一个虚假的复合指标，抹平企业间的不对称——而那个不对称才是决策依据。**分维度单独呈现。**
4. **报告必须回答三个问题**，答不上就别收尾：
   - 我们真正的对手是谁？（点名 Direct 层）
   - 靠什么竞争？（一句话说清差异点，且能在矩阵里找到对应列）
   - 这个差异点哪些维度是别人抄不走的护城河、哪些只是入场券？
5. **结尾给"逼决策"的问题，不给"请欣赏分析"的总结。** 例如：
   - 目标位置是真的空着，还是有对手正在进入？
   - 未来 12 个月最尖锐的威胁是哪家，对策是什么？
   - 哪一项落后的维度值得补上、哪一项该主动放弃？

## 四、多源检索纪律

用于所有子代理的搜索执行。这套规则是本 skill「反编造」机制的落地动作。

### 检索执行
1. **先拆子问题**：把任务拆成 3–5 个子问题，逐个检索，不要一次丢一个大词。
2. **每个子问题用 2–3 种关键词变体**，混合通用词和新闻词。
3. **总量目标 15–30 个独立来源**（单子代理 8–15 个即可）。
4. **深读 3–5 篇关键来源全文**，不能只依赖搜索摘要——摘要是最容易产生误读的地方。
5. **来源优先级**：学术 / 官方 / 权威媒体 > 行业垂直媒体 > 企业自述 > 博客 > 论坛。

### 质量六条（硬约束）
1. 每个论断必须有来源。
2. 只有一个来源的说法 → 标注「未验证」。
3. 优先近 12 个月；超过 2 年 → 标注「历史数据」。
4. 找不到就说找不到，写进信息缺口清单。
5. **不许编。** 不知道就写「数据不足」——这是合法答案。
6. 事实与推断分开标注（估计 / 预测 / 观点 各自显式标记）。

### 并行化
宽话题用子代理并行（本 skill 已是 4 路并行）。每个子代理独立检索、独立输出，最后由主会话合成——
**不要让单个子代理自己合成自己的结论**，那正是偏见自洽的来源。
